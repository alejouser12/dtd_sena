# DTD_SENA Frontend

Este proyecto es una adaptación del frontend del sistema NE|XO SENA para la detección de deserción de estudiantes del SENA.

## Estructura
- `index.html`: Página principal con menú de navegación.
- `css/`: Estilos principales.
- `js/`: Scripts para interacción y utilidades.
- `img/`: Imágenes institucionales.
- `config/`: Header y footer reutilizables.

## Uso
1. Coloca la carpeta en tu servidor local (ej: XAMPP).
2. Accede a `index.html` desde el navegador.
3. Personaliza las secciones según los módulos de tu backend.

## Créditos
Basado en el sistema NE|XO SENA. Adaptado para DTD_SENA (2026).
